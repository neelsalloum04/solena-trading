# L'Eau Vive – Gamme Grillen (photos animées)

Vidéo verticale 1080×1920, 10 s, 30 fps, sans son (à ajouter dans Instagram) : les 4 photos du post (rayon, bière Ralph, Ginger Tiger, Panda Cola) animées avec zooms lents, panoramiques et fondus enchaînés.

- `photos/` : photos recadrées depuis les captures (sans l'interface Instagram).
- `index.html` : animation GSAP. `render.cjs` : rendu Playwright + ffmpeg → `leauvive-grillen.mp4`.
